# Data Ingestion, Cleaning & Preprocessing with Pandas

## Project Overview
This project demonstrates a complete data-cleaning workflow using Python and Pandas on a synthetic retail point-of-sale dataset. The dataset contains intentionally introduced data-quality issues for practice and evaluation.

## Objectives
- Inspect raw retail transaction data.
- Identify missing values and duplicate records.
- Standardize inconsistent date formats and data types.
- Handle missing values using appropriate imputation methods.
- Create date-based features such as year, month, and month name.
- Compare data quality before and after cleaning.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Files
- `raw_retail_sales_12000.csv` — original synthetic dataset.
- `clean_dataset.csv` — cleaned dataset.
- `cleaning_summary.csv` — before-and-after quality metrics.
- `cleaning_comparison.png` — visual comparison of missing values and duplicates.
- `Data_Ingestion_Cleaning_Preprocessing.ipynb` — implementation notebook.

## Workflow
1. Data ingestion
2. Data inspection
3. Duplicate detection and removal
4. Missing-value handling
5. Data-type standardization
6. Date feature engineering
7. Before-and-after quality assessment
8. CSV export

## Dataset Note
The dataset is synthetically generated for educational purposes. It does not represent actual company transactions.

## Results
The notebook reports the actual row counts, missing-value counts, duplicate counts, and data-quality changes before and after preprocessing.
